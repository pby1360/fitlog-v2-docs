# FitLog V2 공식 문서

FitLog는 개인 사용자가 운동 루틴을 빠르게 기록하고, 이후 자세 분석 피드백을 받을 수 있도록 만드는 프로젝트입니다. 프로젝트 문서는 이 저장소에서 관리합니다.

| 찾는 내용 | 문서 |
| --- | --- |
| 누구를 위한 서비스인지, v1과 v2에서 무엇을 만드는지 | [비전](product/VISION.md), [제품 요구사항](product/REQUIREMENTS.md) |
| 마일스톤과 출시 판정 | [로드맵](product/ROADMAP.md), [출시 기준](product/RELEASE_CRITERIA.md) |
| 검증된 구현 상태와 다음 작업 | [현재 상태](status/CURRENT_STATUS.md), [백로그](status/BACKLOG.md) |
| 작업 승인·선점·진행·종료 | [작업 실행 현황](status/TASKS.md), [개발 작업 등록과 실행](operations/DEVELOPMENT_WORKFLOW.md) |
| 기능별 요구사항과 설계 | [기능 목록](features/README.md) |
| 시스템 경계, 코드 구조, 데이터와 API | [시스템 개요](architecture/SYSTEM_OVERVIEW.md), [API 목록](api/README.md) |
| 배포 구성과 장애 대응 | [배포](operations/DEPLOYMENT.md), [런북](operations/RUNBOOK.md) |
| 결정 근거, 날짜별 기록, Obsidian 출처 | [ADR](decisions/README.md), [개발 이력](history/README.md), [이관 기록](history/MIGRATION.md) |
| 문서 작성 및 갱신 규칙 | [AGENTS.md](AGENTS.md), [코드·문서 동기화](operations/DOCS_SYNC.md), [PRD 템플릿](templates/PRD_TEMPLATE.md), [Tech Spec 템플릿](templates/TECH_SPEC_TEMPLATE.md), [ADR 템플릿](templates/ADR_TEMPLATE.md) |

문서 상태는 초안, 검토 중, 확정, 보관으로 표기합니다. 이미 시행된 결정과 이력은 확인된 근거와 함께 기록합니다. 요구사항 승인, 코드 확인, 출시 판정의 기준은 [현재 상태](status/CURRENT_STATUS.md)와 [출시 기준](product/RELEASE_CRITERIA.md)에서 확인합니다.
