# 기능 요구사항 템플릿

이 파일을 복사한 뒤 제목과 추적 정보 표를 채운다. 관련 Issue가 있다면 링크를 남긴다.

| 추적 정보 | 내용 |
| --- | --- |
| 문서 상태 | 초안 |
| 원본 출처 | 문서 또는 이슈 링크 |
| 관련 기능 또는 Issue | 기능 ID 또는 이슈 링크 |
| 최종 검증일 | YYYY-MM-DD |
| 관련 설계 | 해당 기능의 Tech Spec 링크 |

## 배경 및 문제 정의

어떤 사용자가 어떤 상황에서 어떤 문제를 겪는지 기록한다.

## 목표

측정 가능한 제품 목표와 성공 지표를 적는다.

## 범위 및 제외 범위

승인받은 범위와 이 단계에 포함하지 않는 범위를 기록한다.

## 사용자 시나리오

사용자의 진입점, 행동, 기대 결과를 순서대로 적는다.

## 기능 요구사항

요구사항에 안정적인 ID를 붙이고 우선순위와 제약을 기록한다.

## 비기능 요구사항

성능, 접근성, 개인정보와 같이 사용하는 동안 충족할 조건을 적는다.

## 수용 기준

행동과 관측할 결과를 함께 기록한다.
