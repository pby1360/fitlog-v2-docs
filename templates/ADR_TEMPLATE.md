# 아키텍처 결정 기록 템플릿

이 파일을 복사한 뒤 제목과 추적 정보 표를 채운다. 관련 Issue가 있다면 링크를 남긴다.

| 추적 정보 | 내용 |
| --- | --- |
| 문서 상태 | 초안 |
| 원본 출처 | 문서 또는 이슈 링크 |
| 관련 기능 또는 Issue | 기능 ID 또는 이슈 링크 |
| 최종 검증일 | YYYY-MM-DD |
| 관련 설계 | 영향받는 설계 및 관련 ADR 링크 |

## 배경

결정이 필요한 문제와 제약, 결정 날짜를 적는다.

## 결정

선택한 기술 또는 정책과 상태를 기록한다.

## 고려한 대안

검토한 선택지와 당시 장단점을 적는다.

## 결정 근거

판단에 사용한 출처, 코드, 비용 또는 운영 제약을 적는다.

## 영향

제품, 데이터 모델, API, 배포와 이전 ADR에 미치는 영향을 기록한다.

## 관련 문서

PRD, Tech Spec, 코드 커밋, 이슈와 후속 ADR을 연결한다.
