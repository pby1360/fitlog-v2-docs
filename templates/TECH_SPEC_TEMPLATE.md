# 기술 설계 템플릿

이 파일을 복사한 뒤 제목과 추적 정보 표를 채운다. 관련 Issue가 있다면 링크를 남긴다.

| 추적 정보 | 내용 |
| --- | --- |
| 문서 상태 | 초안 |
| 원본 출처 | 문서 또는 이슈 링크 |
| 관련 기능 또는 Issue | 기능 ID 또는 이슈 링크 |
| 최종 검증일 | YYYY-MM-DD |
| 관련 설계 | 해당 기능의 PRD 및 ADR 링크 |

## 개요 및 관련 PRD

대상 요구사항 ID, 관련 PRD 및 구현 상태를 적는다.

## 기술 설계

컴포넌트 책임, 상태 전이, 호출 흐름과 의존성을 기술한다.

## 설계 대안

고려한 후보 및 장단점과 결정 근거를 기록한다. 장기적 결정은 ADR에 연결한다.

## 데이터 모델

테이블·필드·제약과 기존 데이터의 마이그레이션 및 호환성을 기술한다.

## API 계약

경로, 메서드, 요청 및 응답, 상태 코드와 버전·재시도 정책을 기술한다.

## 예외 처리

오류 조건, 메시지·코드 및 부분 실패 시 복구 방법을 적는다.

## 보안

인증, 권한, 소유권과 민감 데이터의 수명 주기를 적는다.

## 테스트 계획

수용 기준별 테스트와 검증 환경 및 확인 방법을 적는다.

## 위험 및 롤백

변경의 위험, 영향 범위, 되돌릴 조건과 데이터 복구 제약을 적는다.
