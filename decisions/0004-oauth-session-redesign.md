# ADR 0004 · OAuth 계정 식별 및 기기별 세션

## 배경

이전에는 이메일 중심 식별과 회원 레코드의 갱신 토큰을 사용했다. 기기별 로그인 상태와 재시작 중 OAuth 인가 요청의 연속성을 다룰 필요가 있었다.

## 결정

V4에서 제공자와 제공자 사용자 ID로 계정을 식별한다. 웹에는 일회용 교환 코드를 리디렉션하고 서버에서 검증한다. OAuth 인가 요청의 상태와 기기별 갱신 세션은 PostgreSQL에서 관리한다.

## 고려한 대안

이메일 기반 계정 연동, 회원별 단일 갱신 토큰, 메모리 기반 OAuth 요청 상태는 변경 전 코드에 있었다. 추가 대안 평가 기록은 확인되지 않았다.

## 결정 근거

공급자별 계정을 구분하고 데이터베이스에서 일회용 코드·토큰 해시·회전 상태를 추적한다. 기기별 로그아웃과 여러 서버 인스턴스에서의 로그인 흐름을 지원한다.

## 영향

구 클라이언트의 콜백 및 갱신 계약과 호환성을 확인해야 한다. 정상 갱신에서는 토큰 쌍을 교체한다.
