# 운동 세션 요구사항

## 배경 및 문제 정의

운동 중엔 기록할 시간이 짧다. 자주 쓰는 프로그램의 세트 구성과 순서를 세션에서 그대로 활용한다.

## 목표

프로그램을 고르고 무게와 횟수를 기록해 첫 운동을 완료한다.

## 범위 및 제외 범위

C-1–C-3은 v1 P0이다. 휴식 타이머 외 부가기능은 초기 범위에서 제외됐다. 일시정지·재개, 건너뛰기와 세션 편집은 이후 Tech Spec 및 개발 기록에 등장한다. 완전한 무프로그램 시작과 모바일 하단 동작 배치는 M5의 후속 항목이다.

## 사용자 시나리오

프로그램을 선택해 세션을 시작한다. 제시된 종목과 세트를 따라 운동하고, 무게와 반복 횟수를 기록한다. 세트를 완료하면 휴식 타이머가 시작되며 마지막에 세션을 종료한다.

## 기능 요구사항

- 운동을 시작할 때 프로그램의 종목·세트와 순서를 표시한다.
- 세트별 실측 무게·횟수를 기록하고, 기록 후 휴식 타이머를 제공한다.
- 완료 세션을 보존하고 [운동 일지](../workout-history/PRD.md)에서 조회한다.

## 비기능 요구사항

모바일에서 세트 사이 짧은 시간에 사용할 수 있어야 한다. [로드맵](../../product/ROADMAP.md)의 실제 운동 환경 점검 항목을 따른다.

## 수용 기준

프로그램 선택부터 세트 기록, 자동 휴식, 세션 완료, 일지 상세 열기까지 확인한다. 중간에 일시정지 후 재개해 실제 운동시간이 멈춘 시간을 제외하는지도 확인한다.
