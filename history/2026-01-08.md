## 원본 기록

### [2026-01-09] 운동 CRUD 및 프로그램 수정/삭제 구현, 인증/CORS 문제 해결

- **진행 단계:** Feature Implementation, Bug Fix

- **주요 변경 사항:**

  - **[Backend] 운동 마스터(부위, 운동) CRUD API 구현:**

    - `WorkoutController.java`: 운동 부위 및 운동에 대한 `POST`, `PUT`, `DELETE` 엔드포인트 추가.

    - `WorkoutFacade.java`: 운동 마스터 데이터 관리를 위한 비즈니스 로직 처리 계층 추가.

    - `WorkoutService.java`: 운동 부위 및 운동의 생성, 수정, 삭제 로직 구현.

    - `WorkoutPart.java`, `Workout.java`: 데이터 수정을 위한 `update` 메서드 추가.

  - **[Backend] 운동 프로그램 수정 및 삭제 API 구현:**

    - `WorkoutProgramController.java`: `PUT /{programId}`, `DELETE /{programId}` 엔드포인트 추가.

    - `WorkoutProgramFacade.java`, `WorkoutProgramService.java`: 프로그램 수정 및 삭제 로직 구현.

  - **[Backend] 인증 및 구성:**

    - `SecurityConfig.java`: `CorsConfigurationSource` Bean을 추가하여 프론트엔드 개발 환경(`localhost:3000`, `localhost:5173`)의 CORS 요청 문제 해결.

    - `.gitignore`: `application.yml`을 추가하여 Git 추적에서 제외.

  - **[Frontend] 백엔드 API 연동 및 기능 구현:**

    - `src/services/api.ts`: 운동 마스터(부위, 운동) 및 운동 프로그램에 대한 CRUD API 호출 함수(`addWorkoutPart`, `updateWorkoutProgram` 등) 전체 추가.

    - `src/pages/programs/page.tsx`: 기존의 클라이언트 측 임시 데이터 처리 로직을 모두 실제 API 호출로 교체. (운동 부위/운동 추가, 수정, 삭제 기능, 프로그램 수정/삭제 기능)

  - **[Frontend] 토큰 유효성 검사 및 자동 로그아웃:**

    - `src/App.tsx`: `useEffect` 훅을 사용하여 앱 실행 시 토큰 유효성 검사 로직 추가.

    - `src/services/api.ts`: 토큰 유효성 검사를 위한 `getMyInfo` 함수 추가. 유효하지 않은 토큰일 경우 `localStorage`에서 토큰을 제거하고 페이지를 새로고침하여 자동 로그아웃 처리.

- **해결된 이슈:**

  - 클라이언트에서 백엔드 API 호출 시 발생하던 **CORS policy 오류**를 서버에서 해결.

  - 만료되거나 유효하지 않은 토큰이 클라이언트에 남아있을 경우의 **자동 로그아웃 처리 부재 문제** 해결.

  - 운동 프로그램 페이지에서 **운동 부위 및 운동을 추가, 수정, 삭제할 수 없었던 문제**를 백엔드 API 연동으로 해결.

  - **운동 프로그램을 수정하고 삭제할 수 없었던 문제**를 백엔드 API 연동으로 해결.
