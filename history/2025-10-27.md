## 원본 기록

1. **신규 프로젝트 환경 구축**

    - `fitlog-v2-server` (Spring), `fitlog-v2-web` (Vue) GitHub 레포지토리를 생성했습니다.

    - `Docker Compose`를 이용해 로컬 `PostgreSQL` 개발 환경을 구축하고 `application.yml` 연동을 완료했습니다.

2. **핵심 도메인 및 패키지 구조 설계**

    - `global` (공통)과 `domain` (기능)으로 분리된 확장 가능한 패키지 구조를 적용했습니다.

    - `Member` 도메인의 핵심 코드 (`Entity`, `Repository`, `Service`, `Controller`) 뼈대를 작성했습니다.

3. **Spring Security OAuth2 로그인 흐름 완성**

    - 기본 폼 로그인(`formLogin`)과 `httpBasic` 인증을 비활성화했습니다.

    - JWT 토큰 생성을 위한 `build.gradle` 의존성 추가 및 `TokenProvider` 유틸을 구현했습니다.

    - 구글/카카오의 각기 다른 사용자 정보를 `OAuthAttributes` DTO로 정규화했습니다.

    - `CustomOAuth2UserService`를 구현하여, 소셜 로그인 시 DB에 사용자를 **자동 가입/업데이트**하는 로직을 완성했습니다.

    - `OAuth2LoginSuccessHandler`를 구현하여, 로그인 성공 시 **JWT(Access/Refresh)를 발급**하고 프론트엔드(`client-url`)로 리다이렉트시키는 흐름을 만들었습니다.

    - `WebConfig`로 프론트엔드 서버(`localhost:3000`)를 위한 **CORS 설정**을 완료했습니다.

    - 이 모든 것을 `SecurityConfig`에 통합하여 OAuth2 인증 파이프라인을 구축했습니다.

### 다음 작업 계획 (To-Do)

오늘은 **'로그인(인증)'** 자체를 구현했다면, 다음은 **'로그인된 사용자를 확인(인가)'**하는 필터를 구현하고 v1의 핵심 기능을 만들어나갈 차례입니다.

1. **[1순위] JWT 인증 필터 구현 (가장 중요)**

    - 현재는 로그인 '성공' 시점만 처리했습니다.

    - 이제 프론트엔드(Vue)가 API 요청 시 `Authorization: Bearer <Access_Token>` 헤더에 담아 보낸 토큰을 **검증(Validate)**해야 합니다.

    - `TokenProvider`를 이용해 토큰을 검증하고, 유효하면 `SecurityContextHolder`에 사용자 정보를 저장하는 **`JwtAuthenticationFilter`**를 구현해야 합니다.

    - 이 필터를 `SecurityConfig`에 `addFilterBefore`로 등록해야 합니다.

2. **[2순위] OAuth2/API 실제 테스트**

    - Google·Kakao 콘솔에서 발급한 자격증명으로 당시 로컬 설정을 구성합니다.

    - 브라우저에서 `http://localhost:8080/oauth2/authorization/google`로 접속해 실제 로그인 흐름이 동작하는지, 프론트엔드 URL로 토큰과 함께 리다이렉트 되는지 확인합니다.

    - (Postman 등으로) 발급받은 Access Token을 헤더에 넣어 `/api/members/me` (인증이 필요한 API) 호출이 성공하는지 테스트합니다.

3. **[3순위] v1 핵심 도메인 개발 (기획서 기반)**

    - `Workout` (운동 마스터) 도메인: '스쿼트', '벤치프레스' 등 관리자가 관리하는 운동 목록

    - `WorkoutProgram` (루틴 템플릿) 도메인: 사용자가 '나의 3분할-가슴' 같은 템플릿을 CRUD 하는 기능

    - `WorkoutRoutine` (오늘의 운동 일지) 도메인: `WorkoutProgram`을 불러와 실제 무게/횟수를 기록하는 핵심 기능

4. **[4순위] `fitlog-v2-web` (Vue) 작업 시작**

    - Vue 3 + Vite 프로젝트 생성

    - 로그인 페이지 (구글/카카오 로그인 버튼) 구현

    - `/auth/callback` 라우터 구현 (URL 쿼리로 넘어온 토큰을 `localStorage` 등에 저장)
