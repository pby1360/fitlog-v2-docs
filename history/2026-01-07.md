## 원본 기록

### [2026-01-08] 운동 프로그램 CRUD (생성, 조회) 및 기반 개선

- **진행 단계:** Feature Implementation, Refactoring, Bug Fix

- **주요 변경 사항:**

  - **[Backend] 운동 프로그램 생성 및 조회 API 구현:**

    - `WorkoutProgramDto.java`: `Request` DTO를 `id` 기반으로 리팩토링 (`workoutPartId`, `workoutId` 사용). `Response` DTO (`ProgramResponse`, `ProgramPartDto`, `ProgramExerciseDto`, `ProgramSetDto`) 추가.

    - `WorkoutService.java`: `findWorkoutPartById`, `findWorkoutById` 메서드 추가하여 `id` 기반 조회 지원.

    - `WorkoutProgramService.java`: `createWorkoutProgram` 로직을 `id` 기반 조회로 변경. `findAllPrograms` 메서드 추가하여 프로그램 목록 조회 기능 구현.

    - `WorkoutProgramFacade.java`: `findAllPrograms` 메서드 추가.

    - `WorkoutProgramController.java`: `GET /api/workout-programs` 엔드포인트 추가하여 프로그램 목록 조회.

  - **[Backend] 데이터 무결성 강화:**

    - `Workout.java` 엔티티에 `name`과 `workout_part_id` 조합에 대한 복합 유니크 제약 조건 추가 (`@Table(uniqueConstraints)`).

  - **[Backend] API 경로 및 CORS 설정:**

    - `WorkoutProgramController.java`: `@RequestMapping`에 `/api` 접두사 추가하여 클라이언트 경로와 일치.

    - `WebConfig.java` 추가: `http://localhost:3000`으로부터의 요청을 허용하는 전역 CORS 설정 구현.

    - `SecurityConfig.java`: `/api/workout-programs/**` 경로에 대한 인증 규칙을 명시적으로 추가하여 405 Method Not Allowed 오류 해결.

- **[Frontend] 운동 프로그램 페이지 백엔드 연동 및 오류 수정:**

  - `src/services/api.ts`: `saveWorkoutProgram` 함수 (`id` 기반 요청) 및 `getWorkoutPrograms` 함수 (프로그램 목록 조회) 추가. `ProgramResponse` 인터페이스 정의.

  - `src/services/api.ts`: `fetchWithAuth` 함수 수정하여 빈 응답 본문 처리 (클라이언트 `Unexpected end of JSON input` 오류 해결).

  - `programs/page.tsx`:

    - `Program` 인터페이스를 서버 응답(`ProgramResponse`)에 맞춰 재정의하고 관련된 중첩 인터페이스(`ProgramPart`, `ProgramExercise`, `ProgramSet`) 정의.

    - `samplePrograms` 제거 및 `programs` 상태 초기값을 빈 배열로 설정.

    - `useEffect` 훅에서 `getWorkoutParts`, `getWorkouts`, `getWorkoutPrograms`를 병렬로 호출하여 초기 데이터 로드.

    - `saveProgram` 함수: 프로그램 저장 페이로드를 `id` 기반으로 구성하도록 로직 변경. 저장 성공 시 `fetchWorkoutPrograms` 호출하여 목록 새로고침.

    - `startEditProgram` 함수: 서버 응답을 클라이언트 상태에 맞게 변환하여 편집 모드 초기화.

    - `getExerciseCount` 및 `getTotalSets` 함수를 새로운 `Program` 인터페이스 구조에 맞게 수정.

    - `deletingProgramId` 상태 타입을 `string | null`에서 `number | null`로 변경.

    - `addExerciseToProgram` 함수를 `CurrentExerciseSet` 타입에 맞게 수정.

    - `updateSet` 함수의 `field` 매개변수 타입을 `CurrentExerciseSet` 내부 세트 객체의 키에 맞게 수정.

- **해결된 이슈:**

  - 백엔드 `WorkoutProgramService`에서 `name` 기반 조회를 `id` 기반 조회로 변경하며 발생한 컴파일/런타임 오류.

  - 클라이언트에서 서버로부터 받은 `ResponseEntity<Void>` 응답을 JSON으로 파싱하려다 발생한 `SyntaxError: Unexpected end of JSON input` 오류.

  - 클라이언트에서 백엔드 API 호출 시 발생한 `CORS policy` 오류 및 `405 Method Not Allowed` 오류.

  - `WorkoutProgramDto.java`에서 엔티티 클래스 import 누락으로 인한 컴파일 오류.

  - `programs/page.tsx`에서 `Program` 인터페이스 및 관련 상태 타입 변경으로 인한 컴파일/런타임 오류.
