### [2026-01-07] 백엔드 운동 마스터 데이터 API 및 프론트엔드 연동

- **진행 단계:** Refactoring

- **주요 변경 사항:**

  - **[Backend] 운동 마스터 데이터 조회 API 구현:**

    - `WorkoutPartRepository`, `WorkoutRepository`에 `findAllByMemberIdOrMemberIsNull` 및 `findByName` 메서드 추가.

    - `WorkoutPartDto`, `WorkoutDto` 생성.

    - `WorkoutService`에 `getWorkoutParts`, `getWorkouts`, `findWorkoutPartByName`, `findWorkoutByName` 메서드 구현.

    - `WorkoutController`에 `/api/workout/parts`, `/api/workout/list` 엔드포인트 구현.

  - **[Frontend] 운동 프로그램 페이지 백엔드 연동:**

    - `src/services/api.ts` 파일 생성 및 `getWorkoutParts`, `getWorkouts` API 호출 함수 정의.

    - `programs/page.tsx`에서 `defaultBodyParts`, `defaultExercises` 샘플 데이터 제거.

    - `programs/page.tsx`에 `useEffect` 훅을 사용하여 컴포넌트 마운트 시 백엔드에서 운동 부위 및 운동 목록 데이터 fetch 로직 추가.

    - `programs/page.tsx` 내의 `Exercise`, `WorkoutPart` 인터페이스 및 관련 상태(`bodyParts`, `exercises`, `newExerciseBodyPart`, `draggedExerciseId`) 타입 수정 및 데이터 처리 로직(추가, 삭제, 수정, 드래그앤드롭, UI 렌더링) 업데이트.

- **해결된 이슈:**

  - 백엔드 `WorkoutProgramService`에서 존재하지 않던 `workoutService.findWorkoutPartByName` 및 `workoutService.findWorkoutByName` 메서드 호출 오류 해결.

  - 프론트엔드 `programs/page.tsx`에서 백엔드 연동 후 발생한 데이터 타입 불일치 및 UI 렌더링 오류 수정.

  - `src/services/api.ts`에서 인증 토큰을 로컬 스토리지 `accessToken`에서 가져오도록 수정.
