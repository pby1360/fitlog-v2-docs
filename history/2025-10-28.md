## 원본 기록

### ✅ 현재까지 완료된 내용 (Done)

1. **Full-Stack 인증 파이프라인 완성**

    - **[프론트]** 로그인 요청 (`/login`)

    - **[백엔드]** OAuth2 공급자(Google/Kakao)로 리디렉션

    - **[백엔드]** 로그인 성공 후 콜백 처리 (`CustomOAuth2UserService`)

    - **[백엔드]** `Member` 엔티티 DB 자동 저장 (회원가입/업데이트)

    - **[백엔드]** JWT (Access/Refresh Token) 발급 (`OAuth2LoginSuccessHandler`)

    - **[프론트]** 콜백 페이지(`_AuthCallbackView_`)에서 토큰 수신

    - **[프론트]** Pinia 스토어(`_useAuthStore_`) 및 `localStorage`에 토큰 저장

    - **[프론트]** `isLoggedIn` 상태 변경 및 UI(로그아웃 버튼) 업데이트

2. **API 요청(인가) 기반 구축**

    - **[백엔드]** `JwtAuthenticationFilter` 구현 완료. (API 요청 시 토큰 검증 준비 완료)

    - **[프론트]** `Axios` 인스턴스 설정 완료. (API 요청 시 자동으로 `Authorization: Bearer <token>` 헤더 탑재 준비 완료)

3. **기본 프로젝트 구조 완성**

    - **[백엔드]** Spring Boot 3 + `domain`/`global` 패키지 구조 + Docker 로컬 DB

    - **[프론트]** Vue 3 + Vite + Vue Router (라우팅) + Pinia (상태 관리)

### 🚀 앞으로 해야 할 일 (v1 MVP 개발)

이제 사용자가 **로그인한 "이후"**에 사용할 수 있는 v1의 핵심 기능을 기획서에 따라 순서대로 개발할 차례입니다.

#### 1. 🛡️ API 인증 최종 테스트 (BE/FE)

- 로그인은 성공했지만, '로그인한 사용자만 접근 가능한 API'가 실제로 동작하는지 최종 확인해야 합니다.

- **[To-Do]**

    1. **[프론트]** `DashboardView.vue`에 있는 '내 정보 가져오기' 버튼을 클릭합니다.

    2. **[백엔드]** `JwtAuthenticationFilter`가 토큰을 정상적으로 검증하는지 확인합니다.

    3. **[백엔드]** `MemberController`의 `/api/members/me` (임시 API)가 정상 응답(200 OK)을 반환하는지 확인합니다. (이때 컨트롤러에서 `@AuthenticationPrincipal`로 사용자 정보를 잘 받아오는지 확인하면 베스트입니다.)


#### 2. 🏋️‍♂️ v1 핵심 도메인 1: `Workout` (운동 마스터) (BE)

- 사용자가 '스쿼트', '벤치프레스' 같은 운동을 선택하려면, 그 운동의 **마스터 데이터**가 DB에 미리 존재해야 합니다.

- **[To-Do]**

    1. **[백엔드]** `domain/workout` 패키지를 생성합니다.

    2. **[백엔드]** `Workout` (운동 종목), `WorkoutPart` (운동 부위 - 가슴/등/어깨 등) 엔티티를 설계합니다.

    3. **[백엔드]** **(중요)** `data.sql` 이나 `ApplicationRunner`를 이용해, **서비스 시작 시 50~100개의 필수 운동 데이터를 DB에 미리 Insert**하는 로직을 구현합니다. (사용자가 직접 '스쿼트'를 입력하게 해선 안 됩니다.)


#### 3. 📝 v1 핵심 도메인 2: `WorkoutProgram` (루틴 템플릿) (BE/FE)

- v1의 킬러 기능인 '템플릿 기반 기록'을 위해, 사용자가 '나만의 루틴 템플릿'을 만들 수 있어야 합니다.

- **[To-Do]**

    1. **[백엔드]** `domain/workoutprogram` 패키지 및 엔티티(e.g., `WorkoutProgram`, `WorkoutProgramItem`)를 설계합니다.

    2. **[백엔드]** 루틴 템플릿 **CRUD API**를 구현합니다. (C: 생성, R: 내 루틴 목록 조회, U: 수정, D: 삭제)

    3. **[프론트]** '내 루틴 관리' 페이지(Vue Component)를 만들고, 위 API와 연동하여 사용자가 템플릿을 만들고 수정할 수 있게 합니다.


#### 4. 🏃‍♂️ v1 핵심 도메인 3: `WorkoutRoutine` (오늘의 운동) (BE/FE)

- 사용자가 템플릿을 기반으로 '오늘의 운동'을 기록하는 **가장 핵심적인 기능**입니다.

- **[To-Do]**

    1. **[백엔드]** `domain/workoutroutine` 패키지 및 엔티티(e.g., `WorkoutRoutine`, `WorkoutRoutineSet`)를 설계합니다.

    2. **[백엔드]** '운동 시작' API (템플릿을 복사해 `WorkoutRoutine` 생성), '세트 기록' API, '운동 완료' API를 구현합니다.

    3. **[프론트]** 메인 화면에서 '운동 시작' 버튼 -> 템플릿 선택 -> '운동 기록' UI (무게/횟수 입력) -> '운동 완료'로 이어지는 핵심 UI/UX를 구현합니다.
