## 원본 기록

### 당시 완료 기록

 1. Full-Stack 인증 파이프라인 완성
     * 프론트엔드 로그인 요청부터 백엔드의 OAuth2 리디렉션, 콜백 처리, Member 엔티티 DB 저장, JWT 토큰 발급
       및 프론트엔드의 토큰 수신 및 상태 관리까지 전체 파이프라인이 완성되었습니다.
 2. API 요청(인가) 기반 구축
     * 백엔드의 JwtAuthenticationFilter와 프론트엔드의 Axios 인스턴스 설정이 완료되어, API 요청 시 토큰 검증
        및 Authorization 헤더 자동 탑재 준비가 완료되었습니다.
 3. 기본 프로젝트 구조 완성
     * 백엔드(Spring Boot 3 + domain/global 패키지 구조 + Docker 로컬 DB)와 프론트엔드(Vue 3 + Vite + Vue
       Router + Pinia)의 기본 프로젝트 구조가 완성되었습니다.
 4. 🛡️ API 인증 최종 테스트 (BE/FE)
     * CustomUserDetails를 생성하고 MemberResponseDto를 업데이트했습니다.
     * MemberController의 /api/members/me 엔드포인트를 @AuthenticationPrincipal CustomUserDetails를 사용하여
        실제 사용자 정보를 반환하도록 수정했습니다.
     * TokenProvider를 업데이트하여 JWT 클레임에 memberId, email, nickname, role을 포함하도록 했습니다.
     * JwtAuthenticationFilter를 수정하여 토큰 클레임에서 CustomUserDetails를 생성하도록 했습니다.
     * OAuth2LoginSuccessHandler를 수정하여 토큰 생성 시 memberId, email, nickname, role을 TokenProvider에
       전달하도록 했습니다.
     * SecurityConfig.java에 OPTIONS 메서드 요청을 permitAll()하도록 추가하여 CORS 사전 요청(preflight)
       문제를 해결했습니다.
     * 이로써 로그인한 사용자만 접근 가능한 API가 정상적으로 동작함을 확인했습니다.

### 당시 작업 계획

이제 사용자가 로그인한 "이후"에 사용할 수 있는 v1의 핵심 기능을 기획서에 따라 순서대로 개발할 차례입니다.

1. 🏋️‍♂️ v1 핵심 도메인 1: Workout (운동 마스터) (BE)

 * 목표: 사용자가 '스쿼트', '벤치프레스' 같은 운동을 선택할 수 있도록, 운동 마스터 데이터를 DB에 미리
   존재하게 합니다.
 * [To-Do]
     1. [백엔드] domain/workout 패키지를 생성합니다.
     2. [백엔드] Workout (운동 종목), WorkoutPart (운동 부위 - 가슴/등/어깨 등) 엔티티를 설계합니다.
     3. [백엔드] (중요) data.sql 이나 ApplicationRunner를 이용해, 서비스 시작 시 50~100개의 필수 운동
        데이터를 DB에 미리 Insert하는 로직을 구현합니다. (사용자가 직접 '스쿼트'를 입력하게 해선 안 됩니다.)

2. 📝 v1 핵심 도메인 2: WorkoutProgram (루틴 템플릿) (BE/FE)

 * 목표: 사용자가 '나만의 루틴 템플릿'을 만들 수 있도록 합니다.
 * [To-Do]
     1. [백엔드] domain/workoutprogram 패키지 및 엔티티(e.g., WorkoutProgram, WorkoutProgramItem)를
        설계합니다.
     2. [백엔드] 루틴 템플릿 CRUD API를 구현합니다. (C: 생성, R: 내 루틴 목록 조회, U: 수정, D: 삭제)
     3. [프론트] '내 루틴 관리' 페이지(Vue Component)를 만들고, 위 API와 연동하여 사용자가 템플릿을 만들고
        수정할 수 있게 합니다.

3. 🏃‍♂️ v1 핵심 도메인 3: WorkoutRoutine (오늘의 운동) (BE/FE)

 * 목표: 사용자가 템플릿을 기반으로 '오늘의 운동'을 기록하는 가장 핵심적인 기능을 구현합니다.
 * [To-Do]
     1. [백엔드] domain/workoutroutine 패키지 및 엔티티(e.g., WorkoutRoutine, WorkoutRoutineSet)를
        설계합니다.
     2. [백엔드] '운동 시작' API (템플릿을 복사해 WorkoutRoutine 생성), '세트 기록' API, '운동 완료' API를
        구현합니다.
     3. [프론트] 메인 화면에서 '운동 시작' 버튼 -> 템플릿 선택 -> '운동 기록' UI (무게/횟수 입력) -> '운동
        완료'로 이어지는 핵심 UI/UX를 구현합니다.

4. 🗓️ v1 핵심 도메인 4: History (캘린더/일지) (BE/FE)

 * 목표: 기록한 운동을 돌아볼 수 있게 합니다.
 * [To-Do]
     1. [백엔드] 특정 날짜/월의 WorkoutRoutine 완료 기록을 조회하는 API를 구현합니다.
     2. [프론트] '캘린더' 컴포넌트를 구현하고, 운동한 날짜를 표시. 날짜 클릭 시 해당 일의 운동 기록(D-2)을
        보여줍니다.
