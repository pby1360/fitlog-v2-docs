## 원본 기록

### 프론트엔드 인증 및 운동 페이지 데이터 연동, 백엔드 인증 응답 개선

- **진행 단계:** Feature Implementation, Bug Fix, Refactoring

- **주요 변경 사항:**

  - **[Backend] 인증 실패 응답 개선:**

    - `fitlog-v2-server/src/main/java/com/fitlog/fitlogv2server/global/security/handler/JwtAuthenticationEntryPoint.java`: `AuthenticationEntryPoint` 구현체를 생성하여, 인증되지 않은 요청 시 `302 Found` 리디렉션 대신 `401 Unauthorized` 응답을 반환하도록 수정.

    - `fitlog-v2-server/src/main/java/com/fitlog/fitlogv2server/global/config/SecurityConfig.java`: `JwtAuthenticationEntryPoint`를 `exceptionHandling()`에 설정하고, `logout().disable()`을 추가하여 API 서버에 적합한 인증 동작을 보장.

  - **[Frontend] 인증 흐름 개선 및 무한 루프 해결:**

    - `fitlog-v2-web/src/services/api.ts`: `fetchWithAuth` 함수 내 `401 Unauthorized` 에러 발생 시 `window.location.reload()` 대신 `navigationService.redirectToHome()`을 호출하도록 변경. 동시 다발적인 `401` 에러 발생 시 단 하나의 알림만 띄우고 리디렉션되도록 `isRedirecting` 플래그 도입.

    - `fitlog-v2-web/src/utils/navigationService.ts`: `useNavigate` 훅을 전역적으로 사용할 수 있도록 `setNavigator`, `getNavigator`, `redirectToHome` 함수를 포함한 유틸리티 파일 생성. `redirectToHome` 함수에 "인증이 만료되었습니다. 다시 로그인해주세요." 알림창 추가.

    - `fitlog-v2-web/src/App.tsx`: `AppNavigator` 헬퍼 컴포넌트를 도입하여 `useNavigate` 훅을 통해 `navigationService`에 `navigate` 함수를 주입. 초기 인증 상태 확인 중 로딩 화면을 표시하여 사용자 경험 개선.

  - **[Frontend] 헤더 사용자 메뉴 이미지 연동:**

    - `fitlog-v2-web/src/components/feature/Header.tsx`: `localStorage`에 저장된 `imageUrl`이 존재하면 해당 이미지를 사용자 아이콘으로 표시하고, 없으면 기본 아이콘을 사용하도록 수정.

  - **[Frontend] 운동 페이지 프로그램 데이터 연동:**

    - `fitlog-v2-web/src/pages/workout/page.tsx`: `defaultExercises` 및 `samplePrograms` 샘플 데이터를 제거하고, `useEffect` 훅을 사용하여 `getWorkoutPrograms` 및 `getWorkouts` API를 통해 서버에서 프로그램 및 운동 목록 데이터를 비동기적으로 가져오도록 수정. `ProgramResponse`를 `Program` 인터페이스에 맞게 변환하는 로직 추가. `getExerciseName`, `getExerciseBodyPart` 함수 및 `startWorkout` 함수가 업데이트된 데이터 구조를 사용하도록 변경.

- **해결된 이슈:**

  - 백엔드에서 인증 실패 시 `302 Found` 리디렉션으로 인해 프론트엔드 SPA에서 발생하던 인증 처리 문제 해결.

  - 인증이 만료된 상태에서 `/programs` 페이지 진입 시 `401` 응답으로 인한 프론트엔드의 무한 루프 현상 해결.

  - 여러 API 요청이 동시에 `401` 에러를 반환할 때 알림창이 여러 번 뜨는 문제 해결.

  - 운동 페이지가 샘플 데이터 대신 실제 서버 프로그램을 사용하도록 변경하여 기능 구현 시작.
